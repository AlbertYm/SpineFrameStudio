# Spine Frame Studio 2026.9.23

Windows 本地视频 / GIF 抽帧素材工作台。版本文件 version.json 是唯一版本依据；程序文件为 SpineFrameStudio_2026.9.23.exe。

## 启动

完整解压 ZIP 后，双击 SpineFrameStudio_2026.9.23.exe。请保留同目录全部文件，不能只复制 EXE。也可使用“打开抽帧工具.bat”运行脚本入口排查启动问题。

适用于 Windows x64。依赖系统 Windows PowerShell 5.1 / .NET Framework。GitHub 公开包不包含 ffmpeg.exe：请从可信来源取得 Windows x64 FFmpeg，把 ffmpeg.exe 放在程序目录或加入系统 PATH。无需 .NET SDK、Python、Node、管理员权限或 AI 服务。此包未做代码签名；受企业应用控制策略限制的电脑可能需要管理员允许执行本地工具。跨机器运行情况需在目标电脑验收。

## 使用

1. 点击“添加素材”或拖入视频 / GIF。列表显示文件名、类型和大小；悬停可查看完整路径。可以多选后移除，Delete 也可移除选中项。
2. 在右侧“抽帧”页选按张数或按 FPS。张数会均匀覆盖整段素材；FPS 留空保留原帧率。画布尺寸留空保持原尺寸，填写如 256x256 则等比缩放并透明补边。
3. 选择一个素材并点击“更新预览”。预览仅显示第一帧，不是时间轴播放器。原图/结果可切换；宽窗口支持并排对照，小窗口自动使用单画布。“100%”表示适合画布时的相对倍率，“适合画布”会重置缩放。
4. “透明与边缘”页可开关抠图，调整背景色、颜色范围、多点取色、柔边、去色溢、收边与最低透明度。背景色留空自动取四角；点击颜色输入框后切到原图点击取色。修改参数后提示更新预览，旧画面不会伪装成最新结果。
5. “导出与工具”页设置 Spine 前缀命名、预览 GIF、描边，或对图片文件夹进行画布缩放。图片目录缩放沿用“抽帧”页画布尺寸，生成新的目录。
6. 在底部选择输出目录，点击“开始导出”。任务在后台运行，底部显示阶段、完成文件数和耗时。完成后点击“打开输出”查看最近一次成功结果。详细日志可以展开；失败时自动展开。

## 停止与安全

批量任务提供“完成本文件后停止”。停止不会中断当前文件的抽帧、抠图和清理，而是在它完成后停止剩余队列，已完成的输出保留。单文件任务及预览要等待完成。执行中关闭窗口会提示等待。

原始视频、GIF 和图片不会覆盖。每次处理生成独立输出目录；失败可能留下空目录或部分输出，请结合日志判断，不要将其当作成功结果。原有 2026.9.14 发布目录和 ZIP 保留，可以直接运行旧版回退。

## 已知边界

- 沿用颜色抠图算法，适用于纯色或接近纯色背景，不是 AI 主体分割。
- 预览只展示第一帧；透明度、遮挡或背景随时间变化时仍需检查导出的多帧。
- 语言切换覆盖主要控件；新任务阶段与部分帮助/错误说明仍优先中文，底层 FFmpeg 诊断保留英文。
- 参数未跨启动保存。后台诊断与预览暂存在系统 TEMP 的 SpineWorkbench_* 目录。
- 本机自动检查与 96 DPI 画布渲染不代表另一台电脑、125% / 150% 缩放及跨显示器切换已人工验收。

## 文件完整性

SHA256SUMS.txt 包含每个发布文件的 SHA-256，供解压后核对。GitHub 公开包包含 EXE、入口/界面/核心/后台脚本、Spine 工程生成模块、原生控件源码、语言文本、版本文件、启动 BAT、许可材料和本说明；FFmpeg 由用户独立配置。内部完整便携包可包含 FFmpeg，但不得在第三方对应源码材料未闭合时作为公开 Release 分发。

## 创建 Spine 序列帧动画

在右侧“Spine 动画”页勾选“抽帧后创建 Spine 动画工程”，填写动画名称和动画 FPS，再开始导出。

- 不选择模板：创建包含 root 骨骼、sequence Slot 和逐帧 attachment 时间轴的新工程。
- 选择 `.spine` 或 Skeleton `.json` 模板：保留模板运行时数据中的骨骼、Slot、Skin、Clipping/Mask、Draw Order、Constraint 和已有动画，再把新序列加入目标 Slot。
- “Mask 内目标 Slot”留空时，程序会从第一个 Clipping attachment 到其结束 Slot 之间自动选择第一个 Slot；复杂模板建议填写准确 Slot 名称。
- 原模板和原始图片不会被修改。每次生成新的 `<动画名>_spine` 目录，重名时自动加编号。
- 所有序列帧必须使用相同画布尺寸；不一致时任务会停止并指出具体文件。

生成 `.spine` 工程需要本机已安装并激活 Spine。当前版本按 Spine 4.1.24 数据格式生成，并自动查找 `C:\Program Files\Spine\Spine.com`。没有 Spine 时，普通 PNG 抽帧仍可使用；勾选工程生成会给出明确错误。Spine 是外部商业软件，不包含在本便携包中。

模板克隆以 Spine JSON 可表达的运行时结构为准。编辑器专属的视图状态、选择状态、未导出的说明信息或其他非运行时元数据不保证保留。建议首次使用某个模板时，在生成工程中检查 Mask 范围、目标 Slot、图片中心和循环接缝。

## 2026.9.23 修复

- 修复 GUI 高频读取 `status.json` 时，后台替换状态文件偶发提示“正由另一进程使用”并中断任务的问题。读取端允许共享删除，写入端使用独立临时文件并对短暂文件占用进行重试。
- 修复部分真实 Mask 模板无法自动确定目标 Slot 的问题。对于 `Clipping end` 指回自身等特殊结构，程序会优先选择模板中已有 Region/Mesh 的非 Clipping Slot，例如 `zhezhao + frame_0001` 会自动选择 `frame_0001`。
- 模板图片目录为空时，按 Spine 规则从模板同目录复制图片；只复制受支持的图片文件，不把 `.spine` 或其他工程文件混入 images。
